# 로지스틱 회귀 · Markdown 기반 재사용 설계

이 설계는 구현 전에 작성합니다. 기준은 `main`의 `fb3bd66`에 있는 [디자인 시스템](../../DESIGN_SYSTEM.md), [컴포넌트 규격](../../docs/DESIGN_COMPONENT_RECIPES.md), [Figure 제작 표준](../../docs/FIGURE_PRODUCTION_STANDARD.md), [재사용 절차](../../docs/REFERENCE_REUSE_WORKFLOW.md)입니다. 기존 8종의 HTML/그림을 복제하지 않고 규격의 역할·수치·검증 방법을 다른 개념에 적용합니다.

## 목표·범위·패턴 선택

대상은 곱셈과 분수는 알지만 이진 분류를 처음 배우는 독자입니다. 3장을 읽고 **입력으로부터 확률을 계산하는 과정과, 확률에 임계값을 적용하는 과정을 구분**할 수 있어야 합니다. 모델 학습·손실 최소화·실제 데이터의 성능 평가는 다루지 않습니다. 입력과 계수는 설명용이며 학습된 가중치라고 주장하지 않습니다.

| 장 | 제목 | 재사용할 패턴 | 한 가지 학습 목표 |
| --- | --- | --- | --- |
| 01 | 로지스틱 회귀의 확률 예측 | #1 Concept의 연속 Figure·한 데이터 경로 | 두 입력 → 점수 → 시그모이드 → 양성 확률 |
| 02 | 한 샘플의 확률 계산 | #4 Step-by-Step의 곱·합·출력 대응 | 각 곱과 절편의 합이 확률식의 입력이 됨 |
| 03 | 임계값에 따른 판정 변화 | #5 Interactive의 고정 샘플·연동 상태 | 확률을 유지하면서 임계값만 바꾸면 판정이 달라짐 |

출력은 `scroll.html`과 `slides.html` 두 개입니다. 세 장은 같은 DOM 생성·계산·상태를 사용하고 모드별로 배치/탐색만 바꿉니다. 원본 8종과 기존 두 모드의 소스는 변경하지 않습니다. 새 자료에 사진·CNN Stack·혼동행렬을 억지로 넣지 않습니다.

| 용어/기호 | 첫 설명 위치 | 화면에 보여줄 뜻 | 이후 표기 |
| --- | --- | --- | --- |
| 로지스틱 회귀(Logistic Regression) | 01 패널 제목·소개 | 두 클래스 중 양성의 확률을 계산하는 분류 모델 | 로지스틱 회귀; 새 약어를 만들지 않음 |
| 입력 특성 x₁/x₂ | 01 입력 Figure·아래 정의 행 | 대상의 속성을 수치로 표현한 두 입력 | 입력, x₁/x₂ |
| 양성(1)·음성(0) | 01 패널 소개 | 이 예제의 두 출력 클래스; 정오·정상/이상과 동일시하지 않음 | 양성/음성 |
| 선형 점수 z | 01 점수 Figure·정의 행 | 입력에 계수를 곱해 절편과 더한 값 | z |
| 시그모이드(Sigmoid) | 01 곡선의 단계 라벨·설명 | 실수 점수를 0과 1 사이로 변환 | 시그모이드 |
| 가중치 w·절편 b | 02 카드 소개, 공식 앞 | 특성에 곱하는 계수 / 입력과 무관하게 더하는 값 | w₁/w₂/b |
| 확률 p | 01 마지막 Figure·정의 행 | 모델의 양성 예측 확률 | p |
| 임계값(Threshold) t | 03 카드 소개, 조작 앞 | 양성으로 판정하는 최소 확률 | 임계값, t |
| 자연상수 e | 02 확률식 바로 아래 | 약 2.718인 지수함수의 밑 | e |

01의 점수 Figure는 아직 정의하지 않은 w/b 수식을 먼저 노출하지 않고 z 값과 짧은 의미만 보여줍니다. 02에서 기호를 정의한 뒤 일반식과 대입식을 제시합니다. 정의를 Teal 마지막 캡션·툴팁·Markdown에만 두지 않습니다. 세 장은 연결된 학습 단위이며 Scroll/Slide 모두 같은 보이는 정의를 유지합니다.

## 데이터와 독립 검산값

입력은 단위 없는 설명용 수치입니다. 가중치 `w=[1.2,−0.8]`, 절편 `b=0.1`을 사용합니다.

```text
z = w₁x₁ + w₂x₂ + b
p = 1 / (1 + exp(−z))
prediction = 1 if p >= t else 0
```

| 샘플 | x₁ | x₂ | z | p의 표시값 |
| --- | ---: | ---: | ---: | ---: |
| 1 | −1.0 | 1.0 | −1.9 | 13.0% |
| 2 | −0.5 | 0.5 | −0.9 | 28.9% |
| 3 | 0.25 | 0.5 | 0.0 | 50.0% |
| 4 | 1.0 | 0.5 | 0.9 | 71.1% |
| 5 | 1.5 | 0.25 | 1.7 | 84.6% |
| 6 | 2.0 | 0.5 | 2.1 | 89.1% |

基本 선택은 샘플 4, 임계값은 **0.60**입니다. 01/02는 동일한 선택 샘플을 설명합니다. 기본 계산은 `1.2×1.0 + (−0.8)×0.5 + 0.1 = 1.20−0.40+0.10 = 0.90`, `p≈0.710949502625004=71.1%`입니다. 기본 판정은 1–3 음성, 4–6 양성으로 각각 3개입니다.

03에서 샘플을 선택하면 01/02의 입력·곱·합·곡선 점·확률도 같은 데이터로 바뀝니다. 임계값만 바꾸면 z/p·막대 길이·샘플 위치는 변하지 않고 판정 배지·개수·비교식만 바뀝니다. 실제 정답 라벨이 없으므로 Accuracy·Precision·Recall을 만들지 않습니다.

반올림은 표시 단계에만 적용합니다. `p>=t`는 반올림 전 값으로 평가하고 동률은 양성입니다. t=0이면 6개 양성, t=1이면 6개 음성입니다. t=0.50에서 샘플 3은 양성, t=0.51에서는 음성입니다. sigmoid는 큰 음수에서 `exp(z)/(1+exp(z))`, 0 이상에서 `1/(1+exp(−z))`로 계산해 지수 오버플로를 피합니다. 수학적으로 유한 z에서 0<p<1이며 극단값의 컴퓨터 표시는 0/1로 반올림될 수 있습니다.

## 01 Figure의 구성과 좌표

한 패널의 제목/소개 아래 4단계를 `1fr 32px 1fr 32px 1.3fr 32px 1fr`로 배치합니다. 각 단계는 Figure **210px**, 라벨 **26px**, 짧은 설명 **44px**, gap **8px**입니다. 같은 단계 높이와 라벨 Y좌표를 유지합니다. Blue connector는 32×16px의 단일 path `M2 8 H29 M23 2 L29 8 L23 14`이며 Figure 슬롯 중심축을 통과합니다. 카드 전체를 잇는 #2의 중심축과 다릅니다.

입력은 x₁/x₂의 두 행, 점수는 z의 수치, 시그모이드는 실제 함수 곡선, 마지막은 p의 수치/막대입니다. 작은 상자를 중첩하는 대신 필요한 입력 행과 수치 묶음만 사용합니다. 하단에는 x/z/p 정의를 가는 구분선 뒤 한 행으로 배치합니다.

시그모이드 SVG viewBox **300×210**, plot x=40…280/y=22…172입니다. z축 범위 −4…4, p축 0…1. `screenX=40+(z+4)/8×240`, `screenY=172−p×150`로 161개 점을 계산합니다. z=0/p=0.5의 보조선은 Muted 계열 점선, 실제 함수는 Blue 3px, 선택 점은 Teal/White. 축/눈금/선택 점은 같은 스케일을 사용합니다. 선택 z가 범위를 벗어나면 x축 범위를 4의 배수로 확장하여 점을 잘라내지 않습니다.

## 02 Figure와 하단 정렬

좌우 **1:1 카드**입니다. 왼쪽은 Label/제목/소개 → 입력·가중치·곱 표 → z 합산, 오른쪽은 같은 Header 높이 → 일반 분수 → 실제 대입 → 소수값·퍼센트입니다. 두 카드 하단 노트의 구분선을 같은 Y좌표에 둡니다.

곱 표는 3열 동일 폭·행 높이 **58px**, 숫자 26px, 머리글 16px입니다. 절편은 별도 행으로 표시하고 곱 표의 두 특성과 혼동하지 않습니다. 분수는 편집 가능한 HTML span과 1px 선, 음수 대입에는 괄호를 사용합니다. 대입식에서 `+ −0.40` 대신 `− 0.40`으로 읽히게 합니다. e의 뜻과 반올림 조건은 각 카드 안의 하단 노트(16px/1.4)에 둡니다.

## 03 조작·샘플·판정 Figure

좌우 비율 **1.07:1**. 왼쪽은 Label/제목/임계값 정의 → 슬라이더/현재값 → 판정 규칙과 점선 범례 → 6개 고정 샘플 행 → 양성/음성 개수입니다. 오른쪽은 선택 샘플의 입력/점수/확률 → p와 t의 비교 → 최종 예측입니다.

슬라이더는 정수 0…100, step1, 기본60이며 표시와 계산에는 나눈 값 0…1을 사용합니다. 샘플 행은 **38px**, 샘플 선택 버튼 **48px**·막대 가변 폭·확률값 **72px**·예측 배지 **60px** 열입니다. 확률 축 0/50/100%, Amber threshold 점선과 그 범례는 판정 규칙 문장과 분리합니다. 6개 행의 x/y·순서는 임계값으로 재정렬하지 않습니다.

예측 양성은 Blue/문자1, 음성은 Muted/문자0. Teal은 연속 확률과 선택 결과의 작은 강조에 사용합니다. 확률과 판정 클래스에 같은 표기/색 의미를 부여하지 않습니다. TP/FP/FN/TN을 쓰지 않습니다.

`threshold`와 선택 `sample`은 URL query, 장은 hash에 저장해 모드 왕복과 새로고침 후 복원합니다. 네이티브 range의 방향키/Home/End를 존중하고 input/button/link focus에서는 페이지 탐색키를 가로채지 않습니다. 결과는 전용 `role=status`로 알리고 전체 Figure를 매 입력마다 다시 읽게 하지 않습니다.

## 실패 상태와 변경 데이터 재사용

로딩 중에는 성공값을 미리 표시하지 않습니다. JS 실행 불가 안내를 두고 초기 렌더링 오류는 명확한 오류 메시지로 전환합니다. 잘못된 URL t/sample은 기본값으로 복원합니다. 편집용 데이터 API는 길이가 다른 특성/계수, NaN/Infinity, 빈 샘플을 거부하며 기존 정상 상태를 부분 갱신하지 않습니다.

별도 검증 데이터는 `w=[0.8,−0.4]`, `b=−0.2`, 샘플 수 **4개**, 입력 `[[-1,0],[0,0],[1,0.5],[2,1]]`입니다. 기본 샘플 수/답을 하드코딩한 구현이 아닌지 확인합니다. 큰 절댓값 z=±1000에서도 NaN이 없어야 합니다.
