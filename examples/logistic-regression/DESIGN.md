01은 그림·키워드·일반식으로 개념만 설명합니다. `x₁/x₂`, `w₁/w₂`, `z=w₁x₁+w₂x₂+b`, `p=σ(z)`를 사용하며 실제 입력/계수/결과는 표시하지 않습니다. 두 특성의 전개식을 써서 벡터 전치 기호 T를 추가로 가르치지 않고 `wᵀx+b`와 같은 정확한 관계를 유지합니다. 02도 같은 네 단계 순서를 유지하고 단계 위에 실제 값을 제시한 뒤 식·그래프·결과를 보여줍니다. 기호·색·흐름은 두 장에서 이어지며 첫 장은 샘플·모델 계수를 바꿔도 같은 일반 개념을 유지합니다.

## 데이터와 독립 검산값

입력은 단위 없는 설명용 수치입니다. 가중치 `w=[1.2,−0.8]`, 절편 `b=0.1`을 사용합니다.

```text
z = w₁x₁ + w₂x₂ + b
p = 1 / (1 + exp(−z))
prediction = 1 if p >= t else 0
```

| 샘플 | x₁ | x₂ | z | p의 표시값 |
| --- | ---: | ---: | ---: | ---: |
| 1 | −1.0 | 1.0 | −1.9 | 13.0% |
| 2 | −0.5 | 0.5 | −0.9 | 28.9% |
| 3 | 0.25 | 0.5 | 0.0 | 50.0% |
| 4 | 1.0 | 0.5 | 0.9 | 71.1% |
| 5 | 1.5 | 0.25 | 1.7 | 84.6% |
| 6 | 2.0 | 0.5 | 2.1 | 89.1% |

수치 예제의 기본 선택은 샘플4, 부록의 임계값은 **0.60**입니다. 02와 부록이 같은 샘플을 사용하며 01은 수치를 사용하지 않습니다. 기본 계산은 `1.2×1.0+(−0.8)×0.5+0.1=1.20−0.40+0.10=0.90`, `p≈0.710949502625004=71.1%`입니다. 부록의 기본 양성/음성은 각각3개입니다.

부록에서 샘플을 선택하면 02의 입력·곱·합·전달 z·확률·그래프의 점/축 값이 갱신됩니다. 01의 기호·일반 곡선은 그대로입니다. 임계값만 바꾸면 z/p·막대 길이·샘플 위치는 변하지 않습니다. 실제 정답이 없으므로 Accuracy·Precision·Recall을 만들지 않습니다.

반올림은 표시 단계에만 적용합니다. `p>=t`는 반올림 전 값으로 평가하고 동률은 양성입니다. t=0이면 6개 양성, t=1이면 6개 음성입니다. t=0.50에서 샘플 3은 양성, t=0.51에서는 음성입니다. sigmoid는 큰 음수에서 `exp(z)/(1+exp(z))`, 0 이상에서 `1/(1+exp(−z))`로 계산해 지수 오버플로를 피합니다. 수학적으로 유한 z에서 0<p<1이며 극단값의 컴퓨터 표시는 0/1로 반올림될 수 있습니다.

## 01 Figure의 구성과 좌표

한 패널의 제목/소개 아래 4단계를 `1fr 32px 1fr 32px 1.3fr 32px 1fr`로 배치합니다. 하단 정의도 **같은 열 토큰**을 사용하여 1/3/5/7번 트랙에 대응합니다. 각 단계는 Figure **210px**, 라벨 **26px**, gap **8px**입니다. 기존의 단계별 짧은 설명 슬롯은 제거하고 의미 설명은 하단 두 줄에 모읍니다. Blue connector는 32×16px의 단일 path `M2 8 H29 M23 2 L29 8 L23 14`이며 Figure 슬롯 중심축을 통과합니다.

입력은 **214px** 폭의 두 박스로 `x₁`, `x₂` 기호(28px)를 중앙 정렬하고 아래에 `가중치 w₁/w₂`(18px)를 둡니다. padding은 **상하16/좌우24px**, 내부 gap8px, 두 박스 gap10px입니다. 값과 등호는 넣지 않습니다. 점수는 일반식 `z=w₁x₁+w₂x₂+b`(26px)만 둡니다. 확률은 `p=σ(z)`(34px)와 `0과1사이의확률`이라는 뜻만 보여주고 퍼센트·확률 막대는 제거합니다.

하단은 x/입력 특성과 가중치 뜻, z/변환 전 점수와 절편 뜻, σ/시그모이드와 자연상수 e, p/양성 확률과 판정 구분의 두 줄입니다. 첫 줄16px, 보조15px/1.4, gap8px이며 대응 Figure와 같은 중앙축입니다. `b=0.10`·`e≈2.718` 같은 값도 여기서 제외하고 02에서 제시합니다. 우상단은 `이진분류·확률모델`입니다.

시그모이드 단계에는 `σ(z)=1/(1+e⁻ᶻ)`(23px)의 Native MathML과 곡선을 함께 둡니다. 함수 괄호는 `stretchy=false`로 분수 높이만큼 늘어나지 않게 합니다. Figure 내부는 함수식44px + gap8px + 곡선158px입니다. 식·분수·지수·곡선의 수학 축은 모두 실제 STIX Two Math입니다.

시그모이드 SVG viewBox **300×210**, plot x=40…280/y=22…172, z축 −4…4/p축0…1입니다. `screenX=40+(z+4)/8×240`, `screenY=172−p×150`로 161개 곡선 점을 계산합니다. 일반적인 0/0.5/1 눈금과 중간 보조선만 유지하고 **샘플의 선택 점·투영선은 없습니다**. 모델·샘플 변경에도 이 곡선과 본문은 바뀌지 않습니다.

## 02 Figure와 하단 정렬

01과 같은 **입력 특성 → 가중합 + 절편 → 시그모이드(Sigmoid) → 확률 출력**의 네 단계입니다. 하나의 White 패널을 사용하고, 두 개의 계산 카드를 잇던 긴 꺾인 z 전달 선·라벨·절대 좌표 계산 코드는 제거합니다. 학습자가 첫 장의 어느 개념을 실제 계산하는지 순서로 대응할 수 있어야 합니다.

그리드는 **1.05fr 32px 1.6fr 32px 1.3fr 32px 0.8fr**, 열 gap8px입니다. 전체 대입식과 그래프에 더 넓은 열을 배분합니다. 모든 단계는 **상단 실제 값100px → Figure230px → 라벨26px**, 사이 gap8px를 공유합니다. 단계의 위 값 구역 시작선과 아래 라벨 Y좌표를 맞춥니다. 패널 안에 별도 제목·소개를 반복하지 않습니다.

| 단계 | 위에 제시할 실제 값 | 아래 Figure·수식 |
| --- | --- | --- |
| 입력 특성 | `입력 x₁=1.00, x₂=0.50` / `가중치 w₁=1.20, w₂=−0.80` / `절편 b=0.10`을 **세 행**으로 분리 | 01과 같은 x₁/x₂ 박스 두 개, 폭200px·상하16/좌우24px 패딩·기호28px 중앙 정렬 |
| 가중합 + 절편 | 계산에서 사용하는 가중치·절편을 두 행으로 다시 대응 | 일반식→전체 대입→결과의 세 줄, 등호 정렬 |
| 시그모이드 | `입력 점수 z=0.90` | `σ(0.90)=1/(1+e⁻⁰·⁹⁰)`와 같은 계산의 실제 교점·축 값·투영선 |
| 확률 출력 | `확률 p≈0.710950` | `p=σ(z)`, Teal의71.1%, 양성 예측 확률의 짧은 뜻 |

네 상단 값 박스는 `.lr-input-chip`의 pale-blue 배경·Blue 문자·20px 값·14px 라벨·padding6px10px·radius8px를 공유합니다. 여러 행은 gap4px, 입력/계수의 라벨 열은40px입니다. 첫 구역은 전체 조건을, 다음 구역은 해당 단계에 쓰는 조건을 제시합니다. 이 예제의 입력·계수는 단위 없는 설명용이며 실제 학습 결과가 아닙니다.

가중합의 세 줄은 다음과 같습니다.

```text
z = w₁x₁ + w₂x₂ + b
  = 1.20×1.00 + (−0.80)×0.50 + 0.10
  = 0.90
```

행별 열은 `24px minmax(0,1fr)`, 열 gap6px, 행 gap14px입니다. 선두 등호의 MathML `lspace="0"`으로26/22/34px의 서로 다른 글자 크기에서도 실제 등호 시작선을 맞춥니다. 음수 인수에만 괄호를 표시하고, 절편의 부호/절댓값을 데이터에서 생성합니다. 여섯 샘플과 대체 모델에서도 전체 대입식이 열을 넘지 않아야 합니다.

세 연결 화살표는 01과 같은 **32×16px 단일 path** `M2 8 H29 M23 2 L29 8 L23 14`, Blue1.8px입니다. 위 margin215px로 Figure의 중앙축 `100+8+230/2=223px`에 화살표 중심을 맞춥니다. 수식 내부나 다른 단계 위를 가로지르는 선을 만들지 않습니다. 고정된 슬롯 안에서 프레임과 함께 비례 축소되므로 탐색·폰트·값 변경 후 별도 연결선 좌표를 갱신할 필요가 없습니다.

시그모이드 Figure는 **대입식44px + gap6px + 그래프180px**입니다. ## 부록 A 조작·샘플·판정 Figure

좌우 비율 **1.07:1**. 임계값 정의는 두 모드에서 동일한 슬라이드 부제에 먼저 둡니다. 왼쪽 카드는 Label/제목 → 16px 구역 간격 → 슬라이더/현재값 → 판정 규칙과 점선 범례 → 6개 고정 샘플 행 → 양성/음성 개수입니다. 오른쪽은 선택 샘플의 입력/점수/확률 → p와 t의 비교 → 최종 예측입니다.

슬라이더는 정수 0…100, step1, 기본60이며 표시와 계산에는 나눈 값 0…1을 사용합니다. 샘플 행은 **36px**, 샘플 선택 버튼 **48px**·막대 가변 폭·확률값 **72px**·예측 배지 **60px** 열입니다. 확률 축 0/50/100%, Amber threshold 점선과 그 범례는 판정 규칙 문장과 분리합니다. 6개 행의 x/y·순서는 임계값으로 재정렬하지 않습니다.

예측 양성은 Blue/문자1, 음성은 Muted/문자0. Teal은 연속 확률과 선택 결과의 작은 강조에 사용합니다. 확률과 판정 클래스에 같은 표기/색 의미를 부여하지 않습니다. TP/FP/FN/TN을 쓰지 않습니다.

`threshold`와 선택 `sample`은 URL query, 장은 hash에 저장해 모드 왕복과 새로고침 후 복원합니다. 네이티브 range의 방향키/Home/End를 존중하고 input/button/link focus에서는 페이지 탐색키를 가로채지 않습니다. 결과는 전용 `role=status`로 알리고 전체 Figure를 매 입력마다 다시 읽게 하지 않습니다. Scroll 문서 끝까지 남은 거리가 2px 이하이면 마지막 장을 현재 장으로 선택합니다. 마지막 장이 상단 140px 읽기 선까지 올라가지 못하는 경우에도 목차/전환 링크가 직전 장을 가리키지 않아야 합니다.

`appendix=1`도 모드 왕복에서 보존합니다. 기본 URL은 본편2장만 렌더링하며 `End`는 계산 장으로 이동합니다. 부록을 닫을 때 부록에 있었다면 본편 마지막 장으로 이동하고, 본편에 있었다면 현재 장을 유지합니다. 임계값과 선택 샘플은 유지합니다. 본편에 부록 요소가 없을 때도 모델·두 그래프·URL·편집 API가 정상 동작해야 합니다.

## 실패 상태와 변경 데이터 재사용

로딩 중에는 성공값을 미리 표시하지 않습니다. JS 실행 불가 안내를 두고 초기 렌더링 오류는 명확한 오류 메시지로 전환합니다. 잘못된 URL t/sample은 기본값으로 복원합니다. `window.LogisticLesson.setModel(model)` 편집 검증 API는 길이가 다른 특성/계수, NaN/Infinity, 빈 샘플을 거부하며 기존 정상 상태를 부분 갱신하지 않습니다. 고정된 한 장의 높이 예산상 표시 API는 **1–6개 샘플**만 허용하며 7개 이상은 추가 장/Scroll 상세 영역으로 나눕니다.

별도 검증 데이터는 `w=[0.8,−0.4]`, `b=−0.2`, 샘플 수 **4개**, 입력 `[[-1,0],[0,0],[1,0.5],[2,1]]`입니다. 기본 샘플 수/답을 하드코딩한 구현이 아닌지 확인합니다. 큰 절댓값 z=±1000에서도 NaN이 없어야 합니다. 이 API의 임시 계수 변경은 URL 상태가 아니며, 새 강의의 영구 데이터는 `model.js`의 단일 기본 모델을 수정합니다. 사용자 UI의 임계값·선택 샘플만 모드 왕복/새로고침에 보존합니다.
