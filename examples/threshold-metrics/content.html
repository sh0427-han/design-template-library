점수와 판정을 가르는 임계값

같은 결함 점수라도 임계값이 달라지면 정상·불량 판정이 바뀔 수 있음

SCORE → DECISION

점수는 모델의 출력, 판정은 기준과 비교한 결과

불량 = 양성(Positive) · 정상 = 음성(Negative) · 실제값(Ground Truth, GT)은 검사로 확인한 정답

입력

s<t정상 예측

0~1 사이의 설명용 합성 점수이며, 보정된 확률이나 실제 모델 성능이 아님

실제값은 고정

검사로 확인한 정답과 모델의 예측을 비교해야 오탐·미탐을 구분할 수 있음

오탐 False Positive · FP

실제 정상→불량 예측

미탐 False Negative · FN

실제 불량→정상 예측

점수·실제값은 그대로임계값을 낮추면 불량 예측이 늘 수 있고, 높이면 줄 수 있음
