## 개념·용어·기술 계약

| 용어 | 보이는 첫 설명 위치와 뜻 | 이후 표기 |
| --- | --- | --- |
| 과적합(Overfitting) | 왼쪽 비교 카드: 학습 데이터의 특성·잡음에 지나치게 맞춰 새 데이터 성능이 저하되는 현상 | 과적합 |
| 일반화(Generalization) | 오른쪽 비교 카드: 학습에 쓰지 않은 새로운 데이터에서도 잘 동작하는 능력 | 일반화 |
| 손실(Loss) | 그래프 제목 아래: 예측 오차의 크기, 낮을수록 좋음 | 학습 손실 / 검증 손실 |
| 학습 데이터 / 검증 데이터 | 범례: 모델을 학습하는 데 사용 / 학습에 쓰지 않고 성능 점검 | 학습 / 검증 |
| 독립 테스트 | 그래프 옆: 모델 선택에 쓰지 않은 별도 데이터로 최종 평가 | 독립 테스트 |

과적합은 현상이고 일반화는 새 데이터 성능의 관점이므로 서로 배타적인 모델 종류나 두 알고리즘으로 그리지 않는다. 비교 카드는 같은 '뜻/살펴볼 대상' 트랙을 사용하되 역할 차이를 명시한다. 학습에서 잘 맞는 모델도 과적합할 수 있다. 검증 데이터로 일반화 성능을 추정하고 설정/모델 선택에 사용할 수 있으나 그 성능을 독립 테스트의 성능으로 부르지 않는다. 단순히 두 손실 사이 차이가 존재한다는 사실만으로 과적합을 확정하지 않는다.

## 데이터·독립 검증 계획

표시 데이터는 편집 가능한 JSON, 학습 진행 u=0…1의 41점. 초기 함수(검증기는 Python 독립 계산): 학습 `0.72 exp(−3u)+0.10`, 검증 `0.60 exp(−4u)+0.20+0.90u²`. 공통 손실축 범위0…1.2. 수치/함수는 설명용 형태의 제작 데이터이며 학습 실험이나 알고리즘의 이론식이 아니다. SVG는 선형 보간, 임의 smoothing/다른 축 사용 없음. 전체41점×2선의 좌표를 독립 계산·대조한다. 데이터 변경 시험은 두 손실이 함께 감소하는 별도41점, 두 선이 교차하는 경계 형태와 잘못된 데이터 거부도 검사한다. 해설은 후반부 상승이 없는 다른 데이터에 과적합 단서를 단정하지 않게 자료 메타데이터와 함께 바꾼다. 학습 실행을 구현하지 않는다.

실제 Chromium으로 1600×950/1440×810/1366×768/1280×720의 Scroll/Slide 8개 캡처를 검사한다. CDP 실제 Pretendard/STIX와 전체−1pt, 카드 padding/정렬, 모든 SVG 라벨 경계·중첩, 선·축·범례, 제목/캡션/Footer, 네트워크/콘솔, 콘텐츠·서식 동일성을 확인한다. 원본8종과 기존 두 예시의 전체 회귀를 실행하며 기존 결과를 재사용 시험 통과로 대체하지 않는다. 구현/자체 검증 후 별도 Reviewer Agent가 기술·디자인·문서 판단을 검토하고 최대3회 수정/재검토한다.
