1. 제목 `과적합과 일반화` → 두 개념의 차이를 보충하는 한 줄 부제.

3. 왼쪽은 학습·검증 손실과 선택/과적합 구간. 그 오른쪽은 원인의 1·2·3 문장.
4. 오른쪽은 학습에 쓴 이미지 → 학습된 모델 → 같은 모델로 새 이미지 A/B 예측.

원인 설명은 작은 선 비교와 추상적인 공통 패턴 설명을 제거하고 다음 세 문장으로 확정했다. 이전 그림의 수치·렌더링 검증 통과를 초보자 이해도의 입증으로 취급하지 않는다.

1. 학습 데이터의 예측 오차를 줄이도록 모델을 맞춤.
2. 지나치게 맞추면 학습 데이터에만 있는 잡음까지 배움.
3. 새 데이터에선 그 잡음이 통하지 않아 오차가 커질 수 있음.

## 손실 그래프의 데이터·좌표

설명용 41점에서 진행 u=0…1, 학습 `0.10+0.72 exp(−3u)`, 검증 `0.20+0.60 exp(−4u)+0.90u²`. 두 계열은 정규화된 예측 대상의 평균제곱오차/무차원/표본별 평균/벌점 제외/같은 평가 모드·고정 분할·같은 목표 분포 조건이다. 이 함수는 학습 알고리즘의 이론식이나 실측 결과가 아니다.

- SVG380×320, plot x46…358/y58…266. `x=46+312u`, `y=266−208loss/1.2`. 학습 Blue3px 실선, 검증 Amber3px 점선8/6, 축Muted1.2px. 회색 보조 격자선 없음.
- [공통 축 계약](../../docs/FIGURE_PRODUCTION_STANDARD.md#그래프-축-이름의-공통-정렬)과 `graph-annotations.js` 사용. y축 이름은−90° 회전/중심Y162/실제 글자 오른쪽X38, x축 이름은중심X202/글자상단Y274. 실제 축과의 간격은 각각8px.
- 검증 손실 argmin은 표시 체크포인트에서 선택, 동률은 첫 시점. 기본 index14/u0.35/점(155.2,186.57724908340626). 이 숫자는 화면에 표시하지 않는다. best.pt는 같은 x좌표/축 아래 baseline315에 둔다. 경계에서는 end-anchor로 넘침을 피하고 선택 x를 바꾸지 않는다.
- 세로 기준선의 명목 y50…296 중 실제 텍스트 bbox±3px는 비운 subpath를 사용한다. 과적합 방향 화살표는 선택 x/y50에서 실제 축끝358/y50까지 같은 tip의 단일 path다. 음영은 같은 선택 x부터 우측 plot 경계까지다.
- `divergence` 해석·내부 최소·최소 이후 검증 상승과 학습 감소를 충족할 때만 과적합 구간/화살표를 표시한다. 동반감소·교차 데이터에는 과적합을 강제하지 않으며 오류 데이터에서는 곡선/선택/영역을 숨긴다.

개념 장에서 숫자 대입 예시를 배제하는 기본 원칙은 유지한다. 모델 선택 시점 표식은 사용자가 요청한 개념적 기준 설명의 C 예외이며, 수치 대입/체크포인트 번호/성능 결과를 보이는 계산 장으로 확장하지 않는다.

## 일반화 Figure의 의미·기하

독립 SVG580×320이다. 학습 이미지3개(붉은/초록 사과, 토마토)와 정답 → 학습된 모델 → 학습에 쓰지 않은 새 A/B → 같은 모델 → 예측 사과/토마토를 연결한다. 두 모델 박스는 같은 `fruit-model` 참조다. A는 노란색/−20°/비대칭 사과, B는18°/굴곡·갈래·하이라이트가 다른 토마토다. 실제 학습·추론을 실행하지 않으며 모든 새 이미지의 성공을 보장하지 않는다.

## 모드와 검증
