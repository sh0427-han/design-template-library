## 기술·개념 확인

부제는 학습에만 지나치게 맞춰 새 데이터 성능이 낮아지는 과적합과, 새 데이터에서도 잘 동작하는 일반화를 비교한다. 카드에서는 '지나치게 맞춰', '새 데이터에서 성능이 저하', '새 데이터에서도 잘 동작'을 강조한다. 단순히 학습 데이터에 잘 맞는 것을 과적합으로 정의하거나 일반화를 별도 알고리즘으로 설명하지 않는다. 일반화 정의의 강제br은 없으며 실제 한 줄 여부는 새 화면에서 확인해야 한다.

Best model은 JSON의 표시 체크포인트 중 검증 손실의 argmin을 찾아 선택한다. 동률이면 먼저 나온 시점을 고른다. 기본41점은 index14/u0.35/검증0.45820817836496386, SVG(155.2,186.57724908340626)이며 독립 수치와 맞는다. 연속 함수의 해석적 최소나 독립 테스트 최적을 주장하지 않는다. 화면에는 선택 기준을 '검증 손실 최소'로 붙이고 접근성 설명/명세에서 '표시된 학습 시점들 중 검증 기준, 독립 테스트 최적 보장 아님'이라고 한정한다. 실제 모델 저장/학습/성능 측정을 수행한 결과라는 주장도 없다.

과적합 영역은 divergence 해석, 내부 최소, 최소 이후 모든 표시 구간의 검증 상승/학습 감소를 함께 만족할 때만 나타난다. 별도 동반 감소/교차 데이터에 같은 과적합 판정을 강제하지 않는다. 선택점과 이후 영역을 추가하는 것은 이번 사용자 요청 범위의 C 설계이며, 최초 개념 장의 선택점 배제 규칙을 모든 자료에 계속 강제할 이유가 없다. 오류 시 곡선뿐 아니라 선택/영역/상태도 숨기는 처리가 있다.

Amber8% 면과 '검증↑·학습↓' 문자가 같은 범위를 설명하고 Teal 선/점/Best label이 최소와 연결된다. 설명용 단조 후반 형태에서는 기술적으로 일관된다. 일반적인 잡음 있는 학습곡선의 임의 상승이나 단순 격차를 항상 과적합으로 확정하는 규칙으로 확대해서는 안 되며 현재 문서가 이번 데이터 형태의 판정으로 한정한다.

## 공통 y축 계약·helper

Figure표준§6의 이전 상단 위 계약을 사용자 요청에 따라 중앙 왼쪽·그룹 전체−90°로 바꿨다. 회전한 실제 글자 bbox의 centerY를 축 상단~하단 중앙에 맞추고 right edge와 y축 사이8px를 둔다. x축 중앙 아래8px, 본문/수학 그룹·원래 서체·−1pt·실제 폰트 후 계산은 유지된다.

helper의 회전 변환을 독립 대수로 확인했다. 원래 bbox(x,y,w,h)에−90° 회전을 적용하면 오른쪽은 y+h, 세로중앙은−x−w/2가 된다. 코드의 translate는 이를 각각 left−8와(top+bottom)/2로 옮기므로 의도한 관계와 일치한다. 두 자료의 검증기도 실제 getBoundingClientRect를 SVG 좌표로 환산해 centerY/right edge/8px를 확인하며, 회전된 일반/수학 글리프의 clipping·문자/곡선·점/투영선 충돌 검사를 유지한다.

이 변경은 기존 상단 위 계약의 숨겨진 오류나 새 문서 누락이 아니라 명시적 사용자 위치 선호의 변경이다. 누적 U2의 부족/보완1건과 최초D0의 당시0건을 지우지 않고 현재 규칙만 바꾼 기록이 적절하다. 기존 승인8종에는 이helper를 자동 적용하지 않는다.
