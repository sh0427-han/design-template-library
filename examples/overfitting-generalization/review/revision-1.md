## 사용자 요청 반영과 개념 정확성

상단 정의 카드의 점검 관점 행을 제거하고 정의만 남겼다. 동일 1:1 열 아래 SVG 두 개를 두어 과적합의 단서와 학습 미사용 검증 데이터에서도 손실이 낮아지는 경우를 비교한다. 양쪽 White와 동일 선/축/범례를 사용해 원본 #3의 대칭 관계를 유지한다. 그림 전체380×320은 종전760×160 대비 절반 폭/두 배 높이이고, 실제 plot312×208은 종전660×104 대비 약절반 폭/정확히두 배 높이다.

일반화는 '학습에 쓰지 않은 데이터에서도 잘 동작하는 능력'으로 정의한다. 오른쪽은 작은 격차만을 성공 기준으로 제시하지 않고 검증 손실 자체도 낮아지는 경우를 그린다. 왼쪽 제목은 검증 손실 상승을 과적합의 '단서'라고 표현해 확정 판정으로 일반화하지 않는다. 좌우가 두 알고리즘이나 동일 모델의 모순된 두 실험이라는 주장은 없다. 새 데이터 성능을 검증 데이터로 살펴보는 예시이며 독립 테스트의 실측 결과로 부르지 않는다.

설명용/실험 아님·상세 측정조건의 화면 부가 문구 삭제는 사용자 우선 지시로 취급한다. JSON의 schematic, 명세, SVG 접근성 설명에 출처·조건·추정의 한계가 남아 있고 실측 성과 주장을 추가하지 않았으므로 공통 MD 결함이나 미준수로 세지 않는다. 다른 주제에 같은 삭제를 일반 규칙으로 확장해서도 안 된다.

## 수학·데이터·검증 코드

- 두 경우의4계열 모두 같은0…1.2 손실 범위와0…1 진행 범위를 쓴다. x46…358/y58…266의 affine mapping이 같고 두 SVG의 축도 같은 좌표다. 같은 평균제곱오차·정규화 대상·무차원·표본별 평균·벌점 제외·동일 평가 조건은 전용 명세/데이터에 있다.
- 왼쪽은 기존 학습함수와 검증함수를 유지한다. 오른쪽 학습함수도 같고 검증은 `0.2+0.6exp(−4u)`로 단조 감소한다. 각41점 독립 계산이 일치하고 모든 손실이 같은 축 범위 안이다.
- 새 검증기는164개 표시좌표를 독립 endpoint interpolation으로 대조하고, 양쪽 SVG의 라벨 경계/충돌, 패딩, 삭제된 점검행/격자/화면 문구,380×320 크기, 실제 폰트·모드 동일성·오류 상태를 검사한다. 오른쪽 잘못된 데이터 거부도 포함한다. 아직 실제 브라우저 실행 결과를 확인한 것은 아니다.
- 변경 데이터2종은 왼쪽을 바꾸고 오른쪽 기본값을 유지한다. 두 그림 모두의 재계산/오류 소거 경로는 검사 대상이지만 임의의 모든 데이터와 해설의 정합성을 보장하는 시험으로 확대하면 안 된다.

경사하강법은 θ²/2, 미분θ, 학습률0.28, 초기2.8,6개 상태,161점이 유지된다. plot x48…290/y20…454로 바꾸면서 곡선/접선/현재·다음점/투영선/갱신 화살표를 새 축으로 계산한다. 변환 계수를 독립 검증기도 갱신했고 수학식은 바뀌지 않았다.345×482는 이전 화면690×338보다 절반 폭/약1.43배 높이이며, plot의 세로 확장은 이전 실제 표시 대비약1.86배다. 16:9의 제목/내용/푸터 안에 맞추기 위한 비율임을 명세에 구분해 기록했으므로 '정확히두배'라고 보고하지 않는다. 회색 장식 격자는 없고 현재·다음점의 의미 있는 투영선은 남긴다.

## 문서 판단과 다음 검토

현행 개정 명세가 종전 D0/D1 절을 대체한다는 범위를 적었고, 종전 오류·실행 기록을 지우지 않았다. #3 주요 적용+#8 축/단위 원칙 일부라는 판단을 유지하며 미사용 패턴·독립 제작자의 처음부터 만드는 재현 시험을 통과했다고 주장하지 않는다. GD를 이번에 수정했으므로 종전의 '두 이전 예시 모두 변경 없음' 보존 증거는 과거 버전의 결과로 한정한다는 기록도 적절하다. 새 공통 Markdown 누락/모순은 발견하지 않았다.

실제 두 자료 각각 PC4×2모드, 글리프/경계/패딩/데이터/실패 상태와 캡처를 받아 후속 시각 검토한다. 특히 길어진 소개, 129px 정의 카드 안쪽 패딩, 서로 다른 그래프의 동일 중앙축, 작은 Slide의 가독성, GD의 하단 변수·축 제목·투영선·갱신 방향과 오른쪽 정의의 실제 위치를 확인해야 한다. 현재 정적 검토 결과만으로 새 프리뷰나 전체 회귀를 통과 처리하지 않는다.
