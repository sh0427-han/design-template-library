## 기술·데이터 독립 확인

Python 표준 `math.exp`로 JSON의 각 점을 독립 계산했다. 41점 모두 진행좌표 `i/40`, 학습 `0.72 exp(−3u)+0.10`, 검증 `0.60 exp(−4u)+0.20+0.90u²`와 절대오차1e−14 이내로 일치한다. 학습 손실은 전 구간 단조 감소한다. 검증 손실은 index14에서 최소이며 이후 상승한다. 범위는 학습0.135846689…~0.82, 검증0.458208178…~1.110989383…로 공통0…1.2 축 안이다.

`curves.js`의 좌표식은 명세의 x62…722/y16…144와 일치한다. 같은 평균제곱오차·표본별 평균·무차원·벌점 제외·같은 평가 조건을 공유한다. 실제 표시 path의 좌표는 Chromium 미실행으로 대조하지 못했다. 변경 데이터·경계·오류 시험도 아직 미수행이다.

과적합은 '현상', 일반화는 '능력'으로 설명해 반대 알고리즘으로 단정하지 않는다. 설명용 곡선/실험 아님을 보이게 표시하며, 학습손실 감소가 언제나 검증손실 증가라는 서술은 없다. 격차만으로 확정하지 않는 조건과 모델 선택에 쓰지 않은 독립 테스트의 최종 평가가 구분되어 있다. 중대한 개념 오류는 발견하지 않았다.
