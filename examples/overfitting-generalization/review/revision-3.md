과적합/일반화의 실제 대표와 작은 PC Slide에서 정의→범례/표제→곡선/축→핵심 해석이 읽힌다. 과적합은 현상, 일반화는 새 데이터에 잘 동작하는 능력이라는 구분이 유지된다. '검증 손실 상승은 과적합의 단서'라는 한정 표현과 오른쪽의 동반 감소 형태가 있어 학습 손실 감소가 항상 검증 손실 증가라는 오해를 강제하지 않는다. 검증을 독립 테스트의 실측 성능으로 부르지도 않는다.

## 지적사항 해결

- REV-R1(개정1차): 손실 정의를 마지막 캡션에서 그래프 앞 소개로 이동. 실제 한 줄 소개가 카드와 겹치지 않음을 확인.
- REV-R2(개정2차): GD의 갱신 설명을 local x225/end/y350으로 이동. 실제 bbox x113.046875…226.629929/y334…354. 다음 라벨도 점 왼쪽 bbox x199.027130…227.386185/y305.316376…325.316376으로 옮겼다. 실제 PNG에서 글자가 곡선·반복점·투영선을 가리지 않으며 양의 기울기/현재/다음/반복/축 기호가 분리된다. 왼쪽 갱신 화살표 방향과 수식은 유지된다.
- REV-T1(개정2차 검사 API 오류): SVG text에 적합한 `text_content()`로 수정 후 변경 데이터부터 실패 안내까지 전체 실행이 완료됐다. 실패했던 최초 상태를 기록에서 지우지 않고 최종 성공과 구분한다.

## 수치·기하·서체 증거

과적합/일반화는41점×4계열 독립 수치오차1.1102230246251565e−16,164개 SVG 좌표 최대오차2.842170943040401e−14.56개 요소의 두 모드/크기 서식·정규화 좌표 차이0px. 모든8화면에서 경계 초과·잘림·라벨 충돌·패딩 침범0, Footer 간격13.125px. 실제 Pretendard/STIX와 전역−1pt, console/request/http 정상 상태가 확인된다. 두 변경 데이터·5종 데이터 거부·키보드/왕복/새로고침/데이터 실패 안내가 모두 통과했다.

GD는 동일 함수/미분/학습률/6상태/161점/접선/화살표 검산을 통과했다. 실제 사용자 폰트·수식·두 모드100요소 서식이 같고 최대 정규화 좌표차이는3.0517578125e−05px. 모든8화면에서 outside/overflow/clipped/overlaps/text collisions/dataCollisions가 빈 배열이다. 새 dataCollisions 검사는 실제 글자 bbox에2px 여유를 두고6개 상태원의 경계와 손실곡선·현재/다음 투영선을 최대0.5SVGpx 간격으로 확인한다. 이전 text-text 검사만으로 통과했던 시각 결함을 이번에는 별도 검출 대상으로 삼았다.

## 재사용성·잔여 범위

#3의 동등 White·대응 행/그림 정렬, #8의 같은 기준/단위/축 원칙 일부를 새 두 그림에 맞게 재구성했다. 새 좌표/비율/문구 삭제는 사용자 개정에 따른 C, 용어 순서·GD 충돌·검사 API는 E이다. 이번에도 새 공통 Markdown 누락/모순0건, 공통 시각 지침 보완0건이며 시험한 범위의 재사용성 '충분' 판단을 유지한다.

이 검토 시점 전체 기존 회귀 실행 `40258756289`는 별도 진행 상태다. 따라서 이전 원본8종/로지스틱 회귀까지 이번 수정 후 전체 회귀를 모두 통과했다고 본 Reviewer가 단정하지 않는다. Builder의 최종 문서에는 확인된 실제 결과만 추가해야 한다. 두 개정 자료 자체의 전용16화면·수학·상태 검증 및 위 시각 문제 해결은 통과로 확인했다.

미사용 패턴의 타주제 재사용, 독립 제작자가 문서만으로 처음부터 만드는 재현 시험, 모바일/태블릿, 실제 스크린리더 청취, 실제 모델 학습/독립 테스트 실측은 이번 승인 범위 밖이다. 경사하강법은 이번에 명시적으로 수정했으므로 '이전 두 예시 모두 변경 없음'이라고 현재 상태를 보고해서는 안 된다. 추가 소스 변경 없이 검증 결과를 기록하는 문서 최종화는 새 디자인 변경과 구분한다.
