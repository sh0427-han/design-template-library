## 요청 항목과 실제 화면

과적합/일반화는 정의 카드의 점검 관점이 사라졌고, 같은 폭/높이의 두 그래프로 바뀌었다. 그래프는 종전보다 좁고 높으며 회색 보조격자가 없다. '설명용 곡선·실험 결과 아님' 화면 부가 문구는 삭제되었고, 사용자 요청에 따라 명세/JSON/접근성 출처를 보존한다. 손실의 뜻은 그래프보다 앞의 한 줄 소개에 있어 개정1차의 용어 순서 문제도 해결했다.

왼쪽에는 검증 손실의 후반 상승과 학습 손실 감소, 오른쪽에는 두 손실이 함께 낮아지는 모습이 보인다. 같은 축/선/범례로 읽히며 일반화를 작은 격차 자체나 과적합과 반대인 알고리즘으로 정의하지 않는다. 정의와 Figure가 같은 열로 대응하고 '과적합의 단서' 표현으로 판정 범위도 제한한다. 새 데이터의 성능을 학습 데이터의 손실만으로 보장할 수 없다는 마지막 해석이 두 그림을 연결한다.

대표 그림과8화면 합성본에서 상단 정의, 범례/축/표제/곡선, 캡션, Footer의 잘림이나 겹침은 발견하지 않았다. 좁은 PC Slide에서도 두 비교 열과 높아진 곡선 형태를 유지한다. 과적합/일반화의 현행 표시 소스/데이터 해시는 실행 JSON과 일치했고 불일치는 API 수정 중인 검증기 파일 하나뿐이었다.

경사하강법도 좁고 높은 곡선, 화면 제작문구 제거, 오른쪽 설명/기호/학습률 주의로 재배치된 모습을 확인했다. 양의 기울기와 왼쪽 갱신 화살표, 현재→다음→반복의 수학적 방향은 맞다. 다만 다음 중간 결함이 있다.

이 신규 기하 오류는 기존 Figure의 글자/도형 겹침 기준이 이미 있으므로 공통 Markdown 누락이 아니다. API 오류 역시 구현 검사 코드 오류이며 공통 시각 규칙 보완으로 세지 않는다.

## 이 시점의 실제 증거

- 과적합/일반화8개 화면의164개 좌표 각각 최대오차2.842170943040401e−14,56개 요소 모드/크기 정규화 좌표 오차0px, Footer 간격13.125px. 카드 padding/글자 경계/라벨 충돌/실제 글꼴·−1pt 검사 통과. 변경 데이터 이후 behavior 검사는 중단되어 미완료다.
- GD8화면, 독립수학/실제폰트/모드/오류처리의 기존 검증기 결과는 passed, source SHA도 일치했다. 이 자동 통과가 Reviewer가 발견한 라벨↔데이터점 충돌을 없었던 것으로 만들지 않는다.
- 두 자료의 전체 변경 검증, GD 시각 결함 수정 및 새 이미지 확인이 필요하다. 최초 D0/D1와 이전 revision-1의 결과는 각 당시 상태로 보존한다.

새 실제 결과를 받으면 이 파일 아래에 재확인 상태를 추가한다. 미사용 패턴·독립 제작 재현 시험·main 병합 승인과는 별개다.

## 수정 후 최종 재확인

후속 `revision-3.md`에서 CI `233d80c`의 새 대표 이미지와 두8화면 합성본을 다시 직접 열어 확인했다. REV-R2는 갱신 설명을 x225/end/y350으로, 다음 라벨을 점 왼쪽으로 옮겨 해결했다. 임시 검토안 x335/end/y421은 투영선 충돌 위험 때문에 최종안으로 채택하지 않았다. 검증도 text-text만이 아니라 글자 경계2px 여유 대 모든 상태원·손실곡선·현재/다음 투영선을 최대0.5SVGpx 간격으로 확인하도록 보완했고 모든8화면 dataCollisions=0이다.

REV-T1은 SVG text를 `text_content()`로 읽도록 수정한 뒤 변경 데이터/거부/탐색/실패 상태까지 전체 passed를 확인했다. 이 파일 위의 failed/보류 상태는 최초 실제 검토 때의 기록이며 지우지 않는다. 최종 개정 범위 한정 판단은 `revision-3.md`를 따른다.
