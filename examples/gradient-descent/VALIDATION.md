### 오류를 기존 지침으로 해결한 증거

- E01: 최초1440×810 Slide의 우측 영역 bottom 약663.98px, 정의 영역 top 약608.06px로 겹쳤습니다. 최종 우측 bottom596.06px, 정의 top608.06px로12px를 확보했습니다. 동일 행의 최대 높이 강제와 중복 설명을 없애고, SVG 슬롯도 실제 예산에 맞췄습니다. 글자 크기를 일괄 축소하지 않았습니다.
- E02: 최초 실제 폰트 감사에서 Unicode 아래첨자 t 두 글리프가 Noto Sans였습니다. 최종 모든 화면에서 본문 Pretendard Variable·수학 STIX Two Math, 대체 글리프0. 지원되는 수학 문자와 tspan을 사용했습니다. 추가 서식 감사에서 SVG 강조 클래스가 수식에 요청하던750 굵기도 Regular400으로 교정하고 검증기에 굵기 단언을 추가했습니다.
- E03: 다음 위치 라벨과 방향 설명의 간격이 약1.5 SVG px였습니다. 방향 설명을 화살표 아래로 옮긴 뒤 텍스트 간 경계 중첩0,8개 실제 캡처를 재검토했습니다.

### 변경·보완한 문서

새 `DESIGN.md`, 이 `VALIDATION.md`, 사례 `README.md`를 추가했습니다. 루트 README/TEMPLATE_CATALOG에는 사례 발견용 링크만 추가했습니다. 공통 규칙의 누락·모순을 확정하지 않았으므로 DESIGN_SYSTEM, FIGURE_PRODUCTION_STANDARD, 컴포넌트 규격,8종 상세 명세, 기존 재사용 프롬프트는 수정하지 않았습니다. 주제 함수·좌표·학습률·표시 크기는 개별 DESIGN에만 있습니다.

CI에는 이 사례의 검증 명령과 프리뷰/화면 artifact 경로를 추가하고, 고정 D0 기준 커밋에 접근할 수 있도록 checkout의 전체 이력을 가져옵니다. 기존 회귀 단계는 유지했습니다. CI가 기존 사례를 회귀 실행하는 것은 그 사례 소스를 새 설계 입력으로 사용하는 것과 구분합니다.

### 미검증·판정 한계

- **독립 저자 블라인드 재현은 아님.** 동일 제작자가 허용된 공통 자료를 읽고 설계·구현했습니다. 이전 대화나 금지된 사례 소스를 근거로 삼지 않는 작업 범위는 지켰지만, 다른 저자가 동일 품질로 재현한다는 증거는 아닙니다.
- 8종 전체 패턴의 새 주제 적용, 공통 지침 수정 전후의 인과적 개선 효과는 검증하지 않았습니다. 이번 결론은 선택한 공통 서식/부분 패턴으로 새 개념 한 장을 만들 수 있었다는 범위입니다.
- 실제 모델 학습, 여러 매개변수의 gradient, 비볼록 손실의 수렴/전역 최적성은 실험하지 않았습니다. 설명용 스칼라 곡선의 검산입니다.
- 모바일, Safari/Firefox, screen reader 전체, 고대비·확대율별 접근성 감사는 범위 밖입니다. 링크 키보드 조작과 기본 semantic/aria만 확인했습니다.
- 최종 소스/프리뷰/문서는 별도 브랜치의 PR로 제출하며 main에는 병합하지 않습니다.
