## 그림과 읽는 순서

한 White 패널을 좌측 손실 곡선과 우측 세 단계 설명으로 구성합니다. 중앙 가는 세로선은 서로 다른 카드가 아닌 동일 개념의 그림/해설을 구분합니다.

1. 좌측: 가로축 매개변수 θ, 세로축 손실 L(θ). 볼록한 그릇 모양은 **매개변수 하나의 설명용 곡선**이며 실제 모델의 학습 기록이 아닙니다. 눈금·측정 단위·수치 성능은 없습니다.
2. 현재 위치의 Amber 접선은 양의 기울기, Blue 수평 화살표는 θ축에서 기울기의 반대 방향으로 갱신함을 나타냅니다. 접선 방향 화살표를 매개변수 갱신 벡터인 것처럼 사용하지 않습니다.
3. 다음 위치와 뒤따르는 Teal 점들은 반복을 나타냅니다. 이는 숫자 대입 문제의 선택 샘플이 아닌 알고리즘의 현재/다음 **기호적 상태**입니다. 화면에는 θ의 실숫값·반복별 손실값·학습률의 특정 수치를 표시하지 않습니다. 공통 개념/상세 분리 지침은 이 의미로 적용합니다.
4. 우측: `기울기 확인 → 반대 방향 갱신 → 다시 반복`. 각 단계 아래 같은 본문 크기의 짧은 설명과 관련 기호식을 둡니다. 갱신 단계에서 학습률을 함께 설명합니다.
5. 패널 하단에는 수식의 기호 정의와 학습률 조건. 마지막 핵심 캡션은 패널 다음, Footer 앞에 둡니다. 화면 바깥에 회색 설명을 추가하지 않습니다.

## 수학적 계약과 독립 검산

한 개의 스칼라 매개변수에 대해 θ_(t+1)=θ_t−ηL′(θ_t), η>0. L′는 현재 θ에 대한 손실의 미분, t는 반복 순서입니다. 여러 매개변수에서는 gradient를 사용하지만 이 장에서는 벡터 미분 기호를 추가하지 않습니다. 양의 기울기에서는 θ가 감소하고 음의 기울기에서는 증가합니다. 최솟값 접근은 설명용 곡선과 적절한 학습률에서의 예이며 일반적인 수렴 보장이 아닙니다.

표시하지 않는 도형 생성 조건: L(θ)=θ²/2, L′(θ)=θ, 초기 θ=2.8, η=0.28, 총 6개 상태. 다음 θ는 0.72배. 곡선 161점, θ 범위 [−3.4,3.4], 손실 범위 [0,6.5]. SVG viewBox 690×360, plot x=[68,644], y=[52,300]. 화면 x=68+(θ+3.4)/6.8×576, y=300−L/6.5×248. 접선은 현재 위치의 L′를 같은 축 배율로 변환합니다. 좌표를 반올림한 표시값에서 다시 계산하지 않습니다. 독립 Python 식과 중앙 차분으로 미분/갱신/손실 감소/접선/경로를 검사합니다. 다른 시작점·학습률에서 부호와 발산 예도 검사합니다.
