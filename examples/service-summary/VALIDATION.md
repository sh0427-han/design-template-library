# 서비스 변경 요약 · 첫 결과 검증

상태: 첫 결과는 외부 교정 전 자체 검증을 완료했으나 **전체 규칙 합격은 아니었다**. 독립 리뷰가 신규 계산 결과/비율의 수학 서체 누락(E)을 발견했고 후속 수정했다. 디자인/D0 선행 commit `3f41256`. 최종 소스·증거는 이 문서가 들어 있는 첫 결과 commit으로 보존한다. D1은 공통 문서 수정본이 아니라 D0 설계를 구현·자체수정한 산출물이다. 공통 입력 변경0. 최초 보존 시 외부 피드백0이었으며 이후 현재 독립 리뷰의 E-01 수정 지시를 반영했다. 이후 commit SHA는 handoff에서 별도로 전달한다.

## D0 충분성과 입증 한계
D0에 기록한 공통 시각 토큰·역할·기준 정규화·검증 절차는 이번 주제에서 재현할 수 있었다. 구현 높이 오류는 문서 부족이 아니라 E였다. 이번 보고의 백분위 정의, 실패 손실 강조, 확대 보류 권고는 C로 분리했다. 첫 완성 결과로 D0의 판단을 과장하거나 모든8종의 타주제 재사용을 통과 처리하지 않는다.

주 사용 패턴은 #8 Executive Summary, #3의 정렬/같은 기준과 #7의 개수·분모 의미를 일부 참고했다. #1/#2/#4/#5/#6 전체 패턴 및 #3/#7 전체 패턴은 새 주제로 검증하지 않았다. 원본8종의 전체 회귀 검사도 실행하지 않았다.

사용자 실제 화면 승인·제품/운영 독자 이해도는 미확인. Firefox/Safari/모바일/태블릿/인쇄/스크린리더 전문 감사·극단적 확대·실제 서비스 통계검정·원시 요청/백분위 산출 방식은 미검증이다. 다른 저장소로 실제 복사 실행하지는 않았으나 검증기는 파일 위치 기반 상대 경로와 설치 도구를 사용하고 현재 저장소 이름/절대 경로에 의존하지 않는다. 공유 자산을 동봉/동일 위치에 유지해야 한다.

로컬 commit 보존만 수행하며 Push/PR/배포/사용자 승인과 구분한다.


## 첫 결과 보존 후 독립 리뷰의 E 수정
- 보존된 최초 결과: `f0f31542a48b560fd2e226439c0e0230f9b2f486`. 당시 JSON/소스/캡처는 해당 Git commit에 남는다. 현재 파일을 수정했다고 최초 평가를 소급해 전체 합격으로 바꾸지 않는다.
- 근거: DESIGN_SYSTEM §본문과 수식의 서체 분리. `.math-number` 적용과 STIX Two Math Regular400/font-synthesis:none은 이미 명시되어 있었으므로 새 공통 D가 아닌 E다. 입력 공통 Markdown 수정 없음.
- 수정: 계산 비율−35.0%/−15.0%/0.5%/0.8%/+60.0%, 퍼센트포인트 숫자+0.3, 계산된 차이280/18/30만 수학 역할로 표시. 한글 단위·일반 텍스트·원시 관측값·번호를 전역 STIX로 바꾸지 않았다.
- 검사 보완: 직접 텍스트 run별 CDP 역할별 실제 서체, 여섯 필수 수학 결과의 coverage,400/합성없음, 두 로컬 WOFF2 응답을 검사. 최초 전역 Pretendard 허용 검사를 대체했다. 독립 Fraction 산술, 모드/기하/오류/8화면 검사 유지.
- 후속 결과와 캡처: 현재 `previews/validation.json` 및8개 PNG가 후속 소스에 대응한다. 실제 실행 결과/직접 시각검토는 아래 완료 기록에 남긴다. 사용자 실제 시각 승인·독자 이해도 미확인 등의 제한은 유지된다.


### 후속 완료 기록 · 2026-11-01
Chromium 154.0.8037.57에서 PC4×2 재렌더 및 **139검사 통과**, 실패0. 8개 최종 PNG를 직접 다시 열어 수학 글리프·한글 단위·원래 숫자·축 정렬·푸터·모드별 크기를 확인했다. 산술/기하/오류 검사와 입력 해시는 모두 통과했다. 수학은 실제 STIX Two Math, 일반 텍스트는 실제 Pretendard로 역할별 CDP 검사했다.

검증기 자체수정: 직접 텍스트 run 감사용 임시 span이 `.axis span` CSS에 걸려 중간 캡처의 눈금을 이동시켰다. 시각검토로 발견한 검증기 E이며 제품 CSS는 바꾸지 않았다. CDP 감사 후 임시 span을 제거한 다음 캡처하도록 수정하고8화면 전체를 재생성·재검증했다. 현재 PNG는 감사용 요소가 없는 실제 DOM의 화면이다.

이 후속 수정의 통과는 최초 결과가 전체 합격이었다는 뜻이 아니다. 최초 소스/JSON/화면 및 평가는 원래 f0f3154 commit에 보존되고, 후속 증거는 별도 수정 commit으로 전달한다. 사용자 시각 승인/독자 이해도는 여전히 미확인이다.
