규칙 기반과 머신러닝의 차이

판단 기준을 누가, 어떻게 만드는지가 핵심적인 차이다.

RULE-BASED

사람이 규칙을 정의

판단에 필요한 규칙을 개발자가 직접 작성한다.

예: 1 + 1 = 2
단순하고 명확한 조건에는 구현과 검증이 쉬움
MACHINE LEARNING

데이터에서 규칙을 학습

학습 목표와 데이터로부터 모델 파라미터를 추정한다.

예: 이미지 속 사과 분류
복잡한 시각 패턴에서는 데이터 기반 학습이 유리할 수 있음
