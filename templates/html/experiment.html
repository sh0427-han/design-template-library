METRICS

같은 데이터의 네 가지 평가 지표

Accuracy

75.0%
TP + TNTP + TN + FP + FN

= 9/12 = 75.0%

Precision

80.0%
TPTP + FP

= 4/5 = 80.0%

Recall

66.7%
TPTP + FN

= 4/6 = 66.7%

F1-score

72.7%
2TP2TP + FP + FN

= 2 × Precision × Recall
/ (Precision + Recall)

= 8/11 = 72.7%
