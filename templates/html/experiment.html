혼동행렬과 평가 지표

12개 샘플로 보는 혼동행렬과 분류 성능

CONFUSION MATRIX

혼동행렬

예시 12개 · 양성: 이상 · 실제 정상/이상 각 6개

모델 예측을 행으로, GT 실제값을 열로 표시한 12개 예시 샘플의 혼동행렬
GT (실제값)
실제 이상실제 정상
모델
예측		예측 이상 TP4 FP1
예측 정상 FN2 TN5

FP: 정상인데 이상으로 예측

FN: 이상인데 정상으로 예측

METRICS

같은 데이터의 네 가지 평가 지표

Accuracy

75.0%

전체 샘플 중 맞힌 비율

TP + TNTP + TN + FP + FN

= 9/12 = 75.0%

Precision

80.0%

이상 예측 중 실제 이상 비율

TPTP + FP

= 4/5 = 80.0%

Recall

66.7%

실제 이상 중 찾아낸 비율

TPTP + FN

= 4/6 = 66.7%

F1-score

72.7%

정밀도·재현율의 조화평균

2TP2TP + FP + FN

= 2 × Precision × Recall
/ (Precision + Recall)

= 8/11 = 72.7%
