# 새 제작 과제 · 서비스 변경 실험 요약

대상 독자: 웹 서비스의 응답 시간·비용·실패 요청 뜻을 아는 성인 제품/운영 담당자. 통계 전문가는 아니다.

목적: 기존 설정과 변경 설정의 예시 관측값을 비교하여, 얻은 이점과 품질 손실을 함께 보고 후속 조치를 결정할 수 있는 의사결정용 요약 한 장을 만든다. 개념 설명 강의가 아닌 수치 근거를 포함한 실험 보고다.

제공 데이터(가상 예시, 실측 성과나 통계적 유의성을 주장하지 않음):
- 각 설정은 동일 요청 혼합/부하 조건에서 별도로 하루 동안 10,000건을 관측했다고 가정한다.
- 응답시간 95백분위수: 기존800ms, 변경520ms.
- 하루 운영 비용: 기존120달러, 변경102달러.
- 실패 요청: 기존50건/10,000건, 변경80건/10,000건.

필수 내용:
- 각 지표의 기존값·변경값·단위를 읽을 수 있게 하고, 응답시간95백분위수의 뜻을 짧게 설명한다.
- 응답시간과 비용의 상대 변화율을 계산한다. 실패율은 각 설정의 비율과 퍼센트포인트 차이, 상대 변화율을 혼동하지 않게 전달한다.
- 단위가 다른 세 지표를 비교할 때 비교 기준을 명시하고, 좋아진 지표와 나빠진 지표를 구분한다. 모든 지표가 개선됐다고 결론 내리지 않는다.
- 데이터 범위를 넘는 인과·일반화·유의성 주장을 피한다. 이 자료로 무엇을 판단할 수 있고 무엇은 추가 확인이 필요한지 밝힌다.
- 관측 결과에 근거한 다음 조치를 간결하게 제안한다.
