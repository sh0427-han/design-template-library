# 제작 과제

대상 독자: 생성형 AI를 처음 배우며 웹 검색과 문서의 개념은 아는 성인 초급자.

학습 목표: 검색 증강 생성(Retrieval-Augmented Generation, RAG)이 질문과 관련된 외부 문서를 찾아 생성 모델의 답변에 활용하는 방식임을 이해하고, 문서 준비와 질문 응답의 역할을 구분한다.

필수 내용:
- RAG의 정식 명칭과 간단한 뜻.
- 문서를 나누고 검색 가능한 표현으로 만들어 저장하는 준비 과정.
- 질문을 검색에 사용하고 관련 문서를 가져와 질문과 함께 생성 모델에 제공하는 응답 과정.
- 저장한 문서와 질문 시 검색의 연결 관계.
- 모델 재학습과 문서 검색의 차이. 검색을 사용해도 답변의 정확성이 자동 보장되지는 않는다는 한계.

분량: 초급자용 개념 슬라이드 한 장. HTML Scroll와 Slide로 제공. 별도 계산 장·부록 없음.
