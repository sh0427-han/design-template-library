- Navy / Blue / Teal 색상과 원래 카드·패널 구조를 유지했습니다. `styles.css`의 `--character-spacing: -1pt`를 상속하고, 제목·본문·캡션·버튼·링크·입력까지 실제 계산 스타일을 확인했습니다.
- Concept은 작은 데스크톱에서도 높이 810px를 유지해 화면 밖으로 나갔고, Experiment·Executive Summary는 1280×720에서 내용이 넘쳤습니다. 데스크톱은 동일한 16:9 캔버스를 뷰포트의 너비·높이에 맞춰 축소하고, 900px 이하에서는 읽기용 세로 배치로 전환합니다.

- 변경 스타일은 8개 HTML에서만 불러오는 `reference-layout.css`에 한정했습니다. 공유 토큰·기존 `styles.css`·`reference-types.css`·Interactive 계산 JS는 변경하지 않았습니다.

## 기술 검산

- Concept: 선택 색 `#E65A46 = RGB(230, 90, 70)`. 입력 그림의 16개 픽셀과 확대 배열 일치. 채널 막대는 각각 `230/255`, `90/255`, `70/255`를 소수 첫째 자리로 반올림.
- Step-by-step: `1×1 + 2×0 + 3×(−1) + 4×1 = 2`. 커널 반전 없음, 단일 채널, bias 0.
- Architecture: `floor((N + 2P − K)/S) + 1`로 첫 Conv 64, Pool 32, 두 번째 Conv 32 검산. GAP은 32개 채널 각각의 공간 평균, Linear는 32→3 logits.
- Experiment: TN=5, FP=1, FN=2, TP=4. Accuracy 9/12=75.0%, Precision 4/5=80.0%, Recall 4/6=66.7%, F1 8/11=72.7%.
- Executive Summary: 120→80, 45→30은 −33.3%, 20→8은 −60.0%. 비교 막대는 각 기존 값 대비 66.67%, 66.67%, 40%.
- Interactive: 기본 0.60에서 TN=2, FP=1, FN=1, TP=2, Precision/Recall 66.7%. 0.00~1.00의 모든 21개 허용 임계값을 별도 계산값과 대조. 점수와 임계값이 같은 0.15에서 양성 처리, 1.00에서 Precision의 `정의 불가` 처리 확인.

## 한계와 후속 검토

- 브라우저 검증 범위는 위 Chromium 버전입니다. macOS/Windows 폰트 및 Safari/Firefox 결과는 별도 확인하지 않았습니다.
- 데스크톱 비례 축소는 현대 브라우저의 CSS `zoom`과 길이 간 나눗셈을 사용합니다. 구형 브라우저 지원은 별도 작업이 필요합니다.
- 가상 데이터는 실제 성능·비용 절감의 근거가 아닙니다. 유형별 최종 디자인 승인 및 실제 콘텐츠 선택은 사용자 검토 대상으로 남깁니다.
- 브라우저 추가 재실행은 환경 권한 대기로 중단됐으나, 그 이전의 성공한 40개 렌더링과 프리뷰 생성 이후 슬라이드 소스 변경은 없습니다. 검산은 별도 정적 계산으로 완료했습니다.
