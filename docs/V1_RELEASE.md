# v1.0.0 · PC HTML 디자인 레퍼런스

2026-11-02 한국 시간, 사용자가 최신 서비스 보고 화면을 확정하고 main 병합과 v1.0 승인을 명시적으로 지시했다. 이번 승인으로 과거 보고서의 승인대기 상태를 현재 승인으로 덮어쓰지 않으며 이 문서를 현재 릴리스 판정으로 사용한다.

## 제공 범위

8종 편집 가능한 HTML 레퍼런스와 PC Scroll/Slide 제작·검토 가이드. 일반 숫자는 Pretendard, 수식만 STIX, 전역−1pt를 적용한다. 최신 사용자 결정은 DESIGN_SYSTEM의 사용자 화면 검토 기준을 따른다. 신규 자료는 실제 화면·산술·폰트·기하를 검토해야 하며 무검토 자동 합격을 보장하지 않는다.

새 제작자 RAG 흐름 조합과 서비스 보고형 #8 전이의 근거를 제공한다. 첫 오류와 수정·독립 검토·사용자 피드백도 보존한다. 서비스 보고의 최종 사용자가 승인한 화면은 예제와 docs/user-screen-review/evidence에 있다. 출시 검증은 CI의 기존8종·원본 interaction·dual-mode·기존 파일럿·최신 서비스 보고 검사를 따른다.

## 승인과 한계

사용자 화면/릴리스 승인은 확인됐다. 실제 대상 독자 이해도, 모든8종의 새 주제 재현, 모든 데이터/조작 조합, 다른 브라우저·모바일·전면 접근성 인증은 미검증이다. 따라서 학습자 이해까지 검증된 범용 자동 생성기로 선언하지 않는다.

PR #29에 포함된 #25~#28 문서/검증 이력을 통합한다. 별도 미병합 PR #24의 Interactive 범용성 보완은 이번 릴리스에서 제외한다. 기존 역사 문서에 있는 OPEN/승인대기/실패 판정은 해당 시점 기록이다.
