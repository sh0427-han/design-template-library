# 4단계 사전 범위

기준: PR #27 OPEN, f368f77b11834c446cde9a69d3b355fdf7fdf48f. 3단계 첫 구현09e824a와 review-first/REVIEW.md, 최종 review-final/REVIEW.md를 근거로 한다. 첫 PASS/부분 패턴 판정은 보존한다.

두 내용 변형만 선택: 긴 제목, 한 노드의 두 줄 설명. 각각 원래 배치와 명시적인 지역 재배치를 비교한다. 추가로 과다 설명의 거부 경계를 시험한다. PC4×2에 같은 fixture를 적용하며 사용자에게 별도 슬라이드·조작 UI를 추가하지 않는다. 음수·축은 이 도식에 없어 시험하지 않는다.

A: 기존 공통 규칙(서체/자간/위계/높이/분량 분리). B: 원본 소스에만 있는 필요한 공통 규칙은 아직 확인하지 못함. C: 변형 텍스트·예제 전용 재배치와 분량 경계. D: 실제 공통 누락/모순 근거가 있을 때만 판정. E: 기존 manifest 경로 오류는 #27에서 수정됨; 남은 오류가 발견되면 코드에서 수정. 문서 탐색 실패는 A 규칙을 찾지 못한 경우로 별도 기록한다.

새 제목 배치는 명시적 author class로 제목/정의를 병렬 배치하여 높이를 재배분한다. font-size나 canvas zoom을 내용량에 따라 낮추지 않는다. 두 줄 SVG 설명은 같은 박스 안의 세 텍스트 기준선을 재배치한다. 한 장을 초과하는 설명은 unsupported로 검출하고 편집/분량 분리를 요청하는 제작 경계로 기록한다. 자동 장 생성은 구현하지 않는다.

공통 디자인 출처: DESIGN_SYSTEM의 행간/간격·높이 배분, DESIGN_COMPONENT_RECIPES §3 PC 창 크기와 텍스트 처리 및 §4 흐름과 구조. 전용 수치는 예제 DESIGN에만 작성한다. 기존 규칙이 충분하면 공통 MD 수정0으로 마감한다.
