# 사용자 화면 검토 반영 · 현행 기준

기준 commit29705ef/PR #29 이후 사용자가 정한 서식 변경이다. 과거 판정을 소급 삭제하지 않는다.

- 일반 숫자·지표·비율·증감값은 계산 결과여도 본문 Pretendard. 별도 수식 내부만 STIX. 애매하면 대상 표기·위치를 지정해 사용자에게 질문한다. 정본은 DESIGN_SYSTEM의 본문과 수식 서체 절이다.
- 최신 사용자 요청으로 화살표와 공통 Y축 숫자를 제거했다. 각 지표 쌍의 최대값을 같은 막대 높이로 맞추고 다른 값은 쌍 내부의 비율로 표시한다. 실패율 악화 막대/수치는 붉은 계열이며 악화 문자도 유지한다.
- 가상 예시/실측 아님 같은 제작 메타 문구는 화면에서 제거했다. 원래 데이터가 가상이라는 출처·생성 조건은 TASK와 DESIGN에 계속 보존한다. 측정/유의성 주장을 새로 추가하지 않았다.
- 이번 보고에는 수식이 없으므로 숫자 전체가 본문 서체다. 과거 STIX 숫자 적용 E 판정은 당시 규칙에 대한 역사이며, 현재 사용자 변경 후의 합격 기준이 아니다.

실제 Chromium PC4×Scroll/Slide, 194검사 통과. 실제 Pretendard 글리프·자간·숫자/박스 경계·산술·쌍별 비율/붉은색·메타 문구 제거·모드 왕복·실패 안내를 검사했다. 막대 높이와 문구를 실제 캡처에서도 확인했다. 사용자 최종 화면 승인/v1 승인/main 병합은 수행하지 않았다.

과거 승인 JSON과 최종 재현 스냅샷은 변경하지 않았다. 문서 검사는 user-design-amendment.json에 기록한 정확한 변경 전후 해시만 허용한 뒤 과거 본문을 기존 승인 해시와 비교한다. 사용자 변경을 과거 승인으로 위장하지 않는다.

최신 사용자 검토: 주요 증감값은 모두 기존 대비 변화율(−35.0%, −15.0%, +60.0%)로 통일했다. 실패율의 +0.3퍼센트포인트는 주요 표시에서 제외하고 원래 비율0.5%/0.8% 및 원시 건수 차이를 분리해 읽게 했다. 산술 의미는 동일하며 퍼센트포인트를 상대%로 바꿔 쓴 것이 아니다.

자명한 설명 제거: 막대 높이 비교법·큰 값의 높이 설명·“관측값의 차이는 비교 가능”을 삭제했다. 화면에는 해석에 필요한 최소 기준 라벨과 처음 다루는 용어 정의만 남긴다. 이 원칙과 생략 예시는 DESIGN_SYSTEM의 “자명한 설명과 제작 메타 문구 생략”에 명시했다.

지표명에서 통계 조건을 분리: “응답시간”을 주요 제목으로, “95백분위수”를 작은 회색 보조 행으로 표시했다. 주요 개념을 먼저 읽고 통계 조건을 확인하도록 한다. 공통 원칙도 DESIGN_SYSTEM에 기록했다.

최신 배치: “95백분위수”는 응답시간 그래프 위의 회색 보조 표기다. 변화율 기준 설명과95백분위수 정의 문장을 제거했다. 보조 설명은 해당 그래프 위에 두며, 주요 지표명/증감값 시작선과 막대 기준선을 맞춘다.
